# REA evidence checklist

These notes capture static observations from the installed Klimper 2.4 ARM64 binary. They support evidence-led investigation; they do not establish 1:1 runtime parity.

- [Project model](PROJECT-MODEL.md): serialized project and recursive section/clip shapes recovered. Recursive section-query routines `FUN_10002ad90` and `FUN_10002b004` establish nested note origins and sequential chord placement; they are project-model queries, not Tonal scorers. The internal unit is 10,368 ticks per whole note and 2,592 per quarter-note beat. Scale-step semantics, pitch meaning, instrument behavior, and several edit transforms remain open.
- [Instrument resolution](INSTRUMENTS-SPEC.md): the persisted Track/ChordTrack descriptor and selector command are string-shaped; an app-side configured `.sf2` path reaches the SoundFont loader, which separately resolves named sources and channel bank/program requests. The descriptor-to-source and Track-to-MIDI-channel connections remain unproven.
- [Section transforms](SECTION-TRANSFORMS.md): serialization, path traversal, a nested-length max update, and one section-append path are recovered. Move/resize/wrap/duplicate operations and descendant offset rules remain unknown.
- [Editing specification](EDITING-SPEC.md): selected-note transpose, time-move deltas, their grouped undo-redo transaction, and a generic length-edit command with a 649-tick minimum are recovered. The item-kind mapping, drag-delta conversion, and other edit operations remain unknown.
- [Harmony](HARMONY.md): Flow, Contrast, Match Notes, and both Tonal callback branches have recovered arithmetic and derived-vector coverage. Palette item construction and voicing arithmetic are partly traced; candidate enumeration/order and score-to-visual mapping remain unknown. Preview Octave/Strumming controls are now statically linked to the palette producer's register/spacing state.
- [Playback](PLAYBACK.md): integer-tick scheduler, event windows, loop-boundary cleanup, and chord-preview spacing/velocity paths are recovered to bounded static code paths. PreviewSettings Octave/Strumming state is directly aliased to the palette producer's register/spacing state. Full-song export, MIDI input, Track-to-channel mapping, producer gain/root-threshold settings, output callback sound behavior, and loop-field mapping remain partial or unknown. Clone smoke evidence describes the clone only.
- [MIDI clip export](MIDI-EXPORT.md): one selected-note clip-drag writer has a scoped SMF specification; this does not specify full-song export or every selection path.
- [Palette reconstruction](PALETTE-SPEC.md): evidence-backed base and extension candidate production, nested record ordering, project-scale/borrow-key/parallel-mode/adjacent-scale control names, and derived voicing vectors; final SwiftUI flattening/order and display mapping remain unresolved.
- [Reconstruction plan](RECONSTRUCTION-PLAN.md): ordered subsystem specifications, evidence gates, source-boundary map, and implementation milestones before prototype work resumes.

All completed claims should cite their REA Evidence IDs, name their evidence type, and state coverage limits. A feature name or persisted field alone is not proof of its user-visible behavior. Keep unresolved claims marked unknown until new static or controlled runtime evidence supports them. No prototype behavior, build, test, or QA result establishes Klimper behavior.
